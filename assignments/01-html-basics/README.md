# Assignment 1: HTML Basics

## Objective
Create a well-structured HTML document that demonstrates semantic HTML elements and proper document structure.

## Requirements
1. Create an HTML document with proper DOCTYPE and meta tags
2. Use semantic HTML5 elements (header, nav, main, section, footer, etc.)
3. Include a form with at least 5 different input types
4. Validate your HTML using the W3C validator

## Deliverables
- `index.html` - Your main HTML file
- `NOTES.md` - Document your learning and any challenges faced
