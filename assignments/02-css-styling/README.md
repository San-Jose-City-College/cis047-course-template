# Assignment 2: CSS Styling

## Objective
Style your HTML document from Assignment 1 using CSS to create an attractive and responsive layout.

## Requirements
1. Create an external CSS file (do not use inline styles)
2. Use CSS Grid or Flexbox for layout
3. Implement a mobile-responsive design using media queries
4. Include at least 3 hover effects
5. Style the form from Assignment 1

## Deliverables
- `style.css` - Your stylesheet
- `index.html` - Updated HTML file linking to your CSS
- `NOTES.md` - Document your design decisions
