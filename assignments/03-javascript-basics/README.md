# Assignment 3: JavaScript Basics

## Objective
Add interactivity to your web page using JavaScript DOM manipulation and event handling.

## Requirements
1. Create an external JavaScript file
2. Add at least 2 different event listeners (click, submit, change, etc.)
3. Manipulate the DOM in response to user actions
4. Create at least 1 function
5. Use console.log() for debugging

## Deliverables
- `script.js` - Your JavaScript file
- `index.html` - Updated HTML file
- `NOTES.md` - Explain your code and functionality
